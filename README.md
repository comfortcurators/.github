Organization-level public metadata for **Comfort Curators Private Limited**.

The rendered GitHub organization profile lives in [`profile/README.md`](./profile/README.md).

## Boundary

This repository is presentation and organization metadata only. It is not an infrastructure source of truth, deployment manifest, runtime inventory or credential store.

Public documentation may describe architecture, products, research and operating principles, but it must preserve the distinction between:

- source/configuration and deployed reality;
- intent and verified outcome;
- company systems and unrelated/personal infrastructure;
- current, legacy, contradicted and unknown states.

Never place secret values, private keys, access tokens, database URLs or production credentials here.
